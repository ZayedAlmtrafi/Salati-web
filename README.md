# 🌙 صلاتي | Slati Web

صلاتي هو موقع بسيط سويته عشان أقدر أتابع صلواتي الخمس بشكل يومي، وأعرف الصلوات اللي صليتها بوقتها واللي تأخرت فيها أو فاتتني.

الفكرة من المشروع هي تسهيل متابعة الصلاة على مدار الشهر، خصوصًا الصلوات الفائتة عشان أقدر أرجع لها وأسجل قضاءها.

## مميزات الموقع

- تسجيل الصلوات الخمس بشكل يومي.
- تحديد حالة كل صلاة (في وقتها، متأخرة، فائتة).
- تسجيل قضاء الصلوات الفائتة.
- عرض إحصائيات شهرية تساعدك تتابع انتظامك.
- إمكانية التنقل بين الأشهر ومراجعة سجلاتك السابقة.
- حفظ البيانات محليًا على الجهاز.
- إمكانية تصدير نسخة احتياطية واسترجاعها.

## طريقة الاستخدام

الموقع يشتغل مباشرة من المتصفح، وتقدر تضيفه للشاشة الرئيسية في جوالك ويصير استخدامه قريب من التطبيق العادي.

**للجوالات:**

1. افتح الموقع من جوالك.
2. اضغط **Share**.
3. اختر **Add to Home Screen**.
4. فعّل **Open as Web App** إذا ظهر، واضغط **Add**.

## التقنيات المستخدمة

المشروع مبني باستخدام:

- **HTML:** لبناء صفحات الموقع.
- **CSS:** لتنسيق التصميم وخليه مناسب للجوال.
- **JavaScript:** لتسجيل الصلوات وحساب الإحصائيات.
- **PWA:** عشان تقدر تثبته من المتصفح ويشتغل بدون إنترنت بعد أول تحميل ناجح.
- **Local Storage:** لحفظ بياناتك على جهازك.

## ملاحظات

الموقع حاليًا ما يوفر مواقيت الصلاة أو تنبيهات تلقائية، وإنما يعتمد على تسجيل المستخدم لصلواته بنفسه.

البيانات تنحفظ على نفس الجهاز، وما تحتاج تسوي حساب عشان تستخدمه. لكن إذا انحذفت بيانات الموقع، ممكن تفقد سجلاتك، لذلك الأفضل تحتفظ بنسخة احتياطية.
